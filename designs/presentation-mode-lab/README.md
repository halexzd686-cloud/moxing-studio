# Presentation Mode Lab

三档展示模式的独立评审原型。它不覆盖现有 24 张生产模板，也不修改已经批准的 `precision-interface-lab`。

## 评审对象

- **A / Direct Canvas — C01**：完整画布，无独立证据仓。适合答案已经直接可读的排名、基础比较和分布图。
- **B / Embedded Evidence — C14**：证据停靠在矩阵自身的自然留白中。适合需要局部推导，但不能牺牲主图宽度的图表。
- **C / Evidence Interface — C06**：数据场、证据仓、终端锁定完整保留。适合推导链、关系链或关键证据需要独立呈现的图表。

## 本轮判断原则

布局模式与动效语法分开选择：

1. 先判断结论是否可以从主图直接读取，决定 A / B / C。
2. 再按图表关系选择 `assemble / trace / route / scan / readout` 动效语法。
3. 单张图只运行 2–4 个宏观动画层；不按柱、点或单元格逐个播放。
4. 证据模块不得覆盖标签、数值、坐标轴或主图有效阅读区域。

## 操作

- 顶部标签切换三种模式。
- `REPLAY` 或空格键重播当前样稿。
- `SURFACE` 或 `D` 键切换明暗表面。

## 状态

`needs-review` — 待确认三档视觉边界后，再映射到 24 张生产模板。
